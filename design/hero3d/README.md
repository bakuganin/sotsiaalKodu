# Первая сцена: домик из Blender

Сейчас на сайте показана исходная статичная иллюстрация [calm-home.webp](../../public/images/calm-home.webp). По просьбе заказчика 3D-сцена, раскрытие и реакция на курсор отключены; компонент `HeroHouse` не подключён к странице. Код `src/hero3d/`, Blender-файл, GLB, освещение и видео сохранены для продолжения позже. Ниже описана сохранённая версия, а не текущее поведение сайта.

Сцена подготовлена в Blender 5.1.2: замкнутая рамка из оливкового стекла с округлыми поверхностями, растение с отдельными листьями и речные камни. Форма создана по мотивам исходной иллюстрации; точное совпадение с ней не предполагается.

## Файлы

- [calm-home.blend](../blender/calm-home.blend) — основной редактируемый исходник: геометрия, материалы, упакованные текстуры, студийный свет, камера и анимация.
- [calm-home-final.png](../blender/calm-home-final.png) — рендер Cycles для оценки материала и света.
- [calm-home.glb](../../public/models/calm-home.glb) — модель для сайта, около 7,0 МБ, с отдельной крышей `Roof_Glass`, материалами, текстурами и анимацией `Reveal`.
- [calm-home-studio.hdr](../../public/models/calm-home-studio.hdr) — панорама студийного освещения из Blender.
- [calm-home.webp](../../public/images/calm-home.webp) — исходная иллюстрация, сейчас постоянно используемая в hero.

Рабочая сцена в исходнике называется `Sotsiaal • Calm Home`. При экспорте выбирается только её коллекция модели; камера, свет и объекты первоначальной сцены в GLB не входят. Высокодетальная рамка остаётся в `.blend`, для GLB применяется упрощение сетки.

[calm-home-reveal.mp4](../blender/calm-home-reveal.mp4) — видеопредпросмотр 720 × 720 px, 4 секунды: около трёх секунд раскрытия и секунда готовой композиции. Файл проверен декодированием в браузере; кадры на 1, 2 и 3,5 секунды показывают подъём домика, рост и готовую композицию.

## Сохранённая 3D-версия: материал и браузер

`src/hero3d/loadBlenderHouse.ts` загружает GLB через `GLTFLoader`, а HDR — через `HDRLoader`. Прежняя процедурная модель не используется. Шейдер `createRasterGlass.ts` применяется к настоящей геометрии Blender: два отдельных прохода сохраняют задние поверхности рамки и крыши, чтобы учитывать их форму при преломлении. Число выборок ограничено; полного поиска пересечений со всеми треугольниками на каждом пикселе нет. Параметры материалов копируются из GLB.

Освещение берётся из HDR через PMREM, цвет отображается через AgX. Для непрозрачных деталей вклад окружения уменьшен до `0.35`, приближая затенение растения и камней стеклянным домиком. Если HDR недоступен, используется встроенное студийное окружение; если устройство не поддерживает буфер задней поверхности с плавающей точкой, остаются исходные физические материалы glTF.

Браузерное стекло приближает результат Cycles: внутренние отражения рассчитаны приближённо, на отдельных краях возможны волнистые искажения. В браузере композиция выглядит светлее и менее объёмно, чем на рендере Cycles. Сохранённый рендер не служит обещанием идентичного изображения на сайте.

## Поведение сохранённой 3D-версии

После `site:ready` домик поднимается от основания, растение вырастает, листья раскрываются. Анимация `Reveal` создана в Blender на 90 кадрах при 30 кадрах в секунду — около трёх секунд. «Раскрыть заново» повторяет её. Сцена использует именованные узлы `House_Root`, `House_Glass`, `Roof_Glass`, `Plant_Root`, `Leaf_Left`, `Leaf_Right`, `Leaf_Top`; эти имена нужно сохранять при редактировании.

Модель плавно следует за мышью в пределах ±12° по горизонтали и ±6° по вертикали; при уходе курсора возвращается. Прокрутка остаётся обычной, меню, услуги и запись доступны постоянно. Следующие страницы книги в эту сцену не входят.

При уменьшенном движении показывается готовая неподвижная композиция. В скрытой вкладке, вне видимой области и при скрытии изображений рендер приостанавливается. После остановки движения кадры не рассчитываются постоянно; разрешение повышается для чёткости.

До первого успешного кадра видна исходная иллюстрация. Ошибка загрузки GLB, отсутствие WebGL, потеря контекста или ошибка шейдера возвращают её. Загрузка ограничена по времени и не блокирует интерфейс. При уходе с главной освобождаются геометрия, материалы, текстуры и графический контекст.

## Проверка и дальнейшее редактирование

[mesh-checks.json](../blender/mesh-checks.json) фиксирует проверку рамки Blender: 107 696 вершин, нет открытых или неманифолдных рёбер и вырожденных граней. Это проверка исходной сетки, а не оценка скорости браузерного рендера.

До отключения 3D все 14 проверок `tests/hero-3d.spec.ts` прошли за 2,2 минуты последовательно, без повторных запусков: раскрытие, курсор, доступность, запасное изображение и ошибки загрузки. Тогда же сборка `npm run build` была успешна. При ширине 390, 1440 и 1920 px сцена загружалась без ошибок и горизонтального переполнения; 320 px были проверены в тестах. Это исторические результаты сохранённой 3D-версии, а не проверка текущего статичного hero. Сейчас этот файл тестов намеренно пропускается с пояснением; перед возвращением компонента нужно снять `test.skip` и проверить сцену заново. Эти результаты не заменяют проверку на всех физических телефонах и видеокартах.

Основной исходник для изменений — `.blend`. Скрипты в `.work/blender-hero/` сохраняют этапы построения, полировки, настройки материала, экспорта и рендера. Это рабочие скрипты отдельных итераций: их нельзя запускать подряд как готовый процесс пересборки, поскольку некоторые повторно изменяют геометрию или параметры материала. После правок исходника нужно обновить GLB, при изменении света — HDR, затем отдельно проверить результат на сайте.
