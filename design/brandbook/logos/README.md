# Kodu — векторный логотип

Основной файл: `kodu-logo-forest.svg`. Символ отдельно: `kodu-symbol-forest.svg`.

Все SVG содержат только векторные контуры: шрифты переведены в кривые, растровых изображений нет. PDF основного логотипа и символа в зелёном и чёрном цвете также полностью векторные. PNG — дополнительные прозрачные превью шириной 2000 px. Белые версии предназначены для тёмного фона.

Варианты: `forest` #283C2D, `ink` #121410, `white` #FFFFFF, `black` #000000. `stacked` — вертикальная композиция; `descriptor` — версия с названием Sotsiaalsete Teenuste Kodu.

Основная композиция: 390.4571 × 116 единиц; знак 80 × 84, слово 250.4571 × 84, расстояние между видимыми контурами 28, технические поля файла 16. Видимая геометрия отдельного знака: x=8…88, y=6…90 на поле 96 × 96. Технические поля файла не заменяют охранное поле, указанное в брендбуке.

Словесная часть построена на Manrope 650; базовый кернинг сохранён, трекинг слегка уменьшен. Знак — собственная геометрия двух открытых арок. Шрифты в соседней папке `fonts` скопированы без изменений из локальных пакетов вместе с лицензиями SIL Open Font License.
