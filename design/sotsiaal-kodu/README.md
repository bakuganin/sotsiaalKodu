# Sotsiaal Kodu — облако, ладонь, крыша и сердце

Новая концепция айдентики для обсуждения, 14 сентября 2026.

Основной знак — асимметричное облако с открытой ладонью в просвете; над рукой расположены мягкая линия крыши и сердце. Крыша и сердце — главный акцент. Ладонь небольшая и второстепенная. Нижний вытянутый палец чуть толще и имеет два мягких изгиба: читаются основание, средняя часть и округлая подушечка. Форма большого пальца сохранена. Знак собран из точных векторных контуров, все просветы действительно прозрачные. Название набрано в две строки: `Sotsiaal / Kodu` — оба слова с заглавной буквы, одним кеглем и насыщенностью, без раздельного масштабирования; рядом доступны однострочная и вертикальная композиции. В документах сохраняется юридическое имя **Sotsiaalsete Teenuste Kodu OÜ**.

## Форматы

SVG — исходные редактируемые контуры, включая всю словесную часть. Они не требуют установки шрифта для корректного отображения. Векторные PDF предназначены для передачи дизайнеру или в печать; в них нет растровых изображений. PNG шириной 2400 px имеют настоящий прозрачный фон и служат дополнительным удобным форматом.

Доступны цвета `forest` (Лист), `grass`, `sprout`, `canopy`, `bud`, `bark`, `cream`, `white`, `black`; у основного логотипа также есть `two-tone`. Основной вариант — Лист на кремовом фоне. Название файла `forest` сохранено для совместимости; его цвет обновлён на #57791D. Светлые цвета не использовать для мелкого текста на светлом фоне. Цветные SVG и PDF — в sRGB; цветоделение для конкретной печати выполняется по профилю типографии.

Минимумы: знак — 48 px / 12 мм; основной логотип — 176 px / 44 мм; однострочная версия — 240 px / 60 мм. Технические поля SVG не заменяют охранное поле: минимум 26 единиц от видимого контура знака. Для вертикальной версии с мелким дескриптором выбирайте ширину от 280 px / 70 мм и проверяйте пробный отпечаток.

Зелёная шкала: #263711 → #57791D → #6A8F24 → #93B947 → #DDE9B8.
Коричневая шкала: #EEE7DC → #D8CABB → #B6A38A → #8A7358 → #5C4934.
Зелёные оттенки — главные. Коричневые — вспомогательные, не более 5% площади цветного декора. Они не заменяют основной цвет кнопок. На ярком ростке используйте текст цвета Крона, на кнопке Лист — белый или кремовый.

Основная гарнитура новой концепции — Manrope; логотип использует вес 600 и переведён в кривые. Лицензии и неизменённые файлы шрифтов находятся в `fonts/`.
